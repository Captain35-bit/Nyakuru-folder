## 🎯 Projects

### [The Book](./the-book/)
**A React Native Mobile App for Note-Taking with Integrated Dictionary**

A powerful note-taking application that combines seamless note management with an integrated dictionary for instant word lookup and learning.

- **Status:** 🚀 Active Development
- **Platform:** Android & iOS (React Native)
- **Tech Stack:** 
  - React Native 0.72.0
  - React Navigation (for routing)
  - Axios (for API calls)
  - AsyncStorage (for local persistence)
  - Jest & ESLint (testing & linting)

**Key Features:**
- 📝 Create, edit, and manage notes effortlessly
- 📚 Integrated dictionary for word lookup
- 💾 Local storage for offline access
- 🔄 Smooth navigation with React Navigation
- ✅ Built with best practices and testing

**Getting Started:**
```bash
cd the-book
npm install
npm start              # Start Metro bundler
npm run android        # For Android
npm run ios           # For iOS
```

**Requirements:**
- Node.js (v14 or higher)
- Android SDK & NDK (for Android development)
- Xcode (for iOS development)
- React Native CLI
